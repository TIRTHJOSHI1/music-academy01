# RudRi Tech — Master Typography Reference

> **STRICT RULE**: When website development starts, ONLY use fonts listed in this approved library.
> Never silently use generic fonts (Arial, Roboto, Inter, system-ui, sans-serif, Geist, etc.) unless explicitly selected from this table.
> If a selected font fails to load, STOP and report the issue instead of automatically substituting another font.
